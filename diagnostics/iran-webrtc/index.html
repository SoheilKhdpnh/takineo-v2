Iran WebRTC reachability diagnostic

Standalone operator tool. It is not the product join UI and is not served through Next.js or Netlify. Run it from a browser on the Iranian network under test, pointing at one candidate LiveKit/TURN host, one transport at a time.

The 15-minute hold never starts on page load. Use Run probes first, then explicitly Start 15-minute hold. Do not put production secrets in config.json; use query params or gitignored config.local.json.

Target

One transport

ICE servers are limited to the selected TURN URL. Other paths are not offered.
