# Takineo

Takineo is a full-stack English-learning platform centered on focused
15-minute speaking sessions with human teachers and AI-assisted feedback.

## Current status

The project is under active development.

## Technology

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Better Auth

Database and authentication integrations will be added in upcoming milestones.

## Requirements

- Node.js 24.x
- npm
- Git
